Azure VM Setup Lab

Objective
Create a basic virtual machine in Microsoft Azure and connect to it securely.

Steps

1. Open Azure Portal
2. Create a Resource Group
3. Create a Virtual Machine
4. Select Ubuntu or Windows Server image
5. Configure username and authentication
6. Allow required ports such as SSH 22 or RDP 3389
7. Connect to the VM
8. Update the server packages

Security Notes

- Use strong passwords or SSH keys
- Do not expose unnecessary ports
- Use Network Security Groups
- Enable MFA on Azure account
