 Azure DevOps Student Labs

This repository contains beginner-friendly cloud and DevOps practice labs created for learning and portfolio building.

Topics Covered

- Microsoft Azure basics
- Azure Virtual Machines
- Linux server commands
- Docker basics
- Git and GitHub workflow
- Cloud security fundamentals
- Basic CI/CD concepts
- Networking basics for cloud

Purpose

The purpose of this repository is to document my learning journey in cloud computing, DevOps, and cybersecurity.  
It includes simple notes, commands, lab steps, and mini projects that can help beginners understand practical cloud concepts.

Labs

1. Azure VM Setup
Basic steps to create and configure a virtual machine in Microsoft Azure.

2. Linux Server Commands
Common Linux commands used for server management and troubleshooting.

3. Docker Basics
Simple Docker commands for building, running, and managing containers.

4. GitHub Workflow
Basic Git commands for pushing code and maintaining project repositories.

5. Cloud Security Notes
Basic security concepts such as MFA, RBAC, NSG, firewall rules, and access control.
